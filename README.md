# Word Burn

A reading game that shows a word, listens for the reader saying it, and measures how quickly they start. Built as a web app that can be added to a phone's home screen.

## What is here now

- `public/`: the microphone test page. It checks whether a phone, opened from a home-screen icon, can hear the instant someone starts saying a word. Nothing is uploaded or stored.

## How it is served

The `gh-pages` branch holds a copy of `public/` and GitHub Pages serves it.

## Rules

- No names, school names or other personal details of any child in this repository. It is public.
